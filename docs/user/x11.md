# Murasaki on X11

`murasaki-surface` (wallpapers) and `murasaki-overlay` (pets) run in an X11 session as well as on Wayland. Nothing is
configured: they use whichever session they are started in (`QT_QPA_PLATFORM=xcb` is chosen by Qt under X11). The
daemon, the GUI, `murasakictl` and all settings are the same.

## What to expect

- **Wallpapers.** One window per screen, drawn as a desktop-type window below everything, on every virtual desktop, out
  of the taskbar and the pager, taking no input and no focus. A desktop environment that draws its own desktop window
  (icons, widgets) keeps it above Murasaki's, as it would above any wallpaper. Window managers that follow the EWMH
  specification (KWin, Mutter, Xfwm4, Openbox, i3, bspwm, Awesome, ...) are supported.
- **Pause when covered.** The surface watches the window manager's own state (`_NET_CLIENT_LIST`, `_NET_ACTIVE_WINDOW`,
  `_NET_WM_STATE`, the virtual desktops): a fullscreen window, a window maximised both ways or one that is as large as the
  screen pauses that screen's wallpaper. Per-desktop wallpapers work with the manager's virtual desktops. The application
  list of *Settings → Pause* works on X11 too (it matches the window's `WM_CLASS`), and so do the game and battery rules.
- **Pets.** Each pet is a frameless window with an alpha channel that the window manager does not manage (override-redirect:
  it is not moved, tiled or decorated), kept above other windows (raised again every couple of seconds), and click-through
  except in arrange mode. **Translucent pets need a compositing manager** (picom, KWin, Mutter, Xfwm4's compositor...);
  without one the area around a pet is drawn black.
- **Spanning** works as on Wayland, with the screens' positions from RandR.

## Limits

- Fractional scaling does not exist on X11: every output is drawn at scale 1.
- The Plasma wallpaper plugin is a Plasma-on-Wayland feature; on X11 use the surface.
- `murasaki-overlay` is built together with LayerShellQt (as before), so the package that provides it must be installed
  even though X11 does not use it.
- Window managers that ignore the EWMH hints show the wallpaper window like any other window; put it below with the
  manager's own rules for windows of class `murasaki-surface`.

## Checking by hand

```bash
xprop -id $(xwininfo -root -tree | grep -i murasaki | head -1 | awk '{print $1}') _NET_WM_WINDOW_TYPE _NET_WM_STATE
```

shows `_NET_WM_WINDOW_TYPE_DESKTOP` and `_NET_WM_STATE_BELOW, _NET_WM_STATE_STICKY, ...` for the wallpaper windows.

## Resumen en espanol

En una sesion X11 `murasaki-surface` y `murasaki-overlay` funcionan igual que en Wayland, sin configurar nada: las ventanas
de fondo son de tipo escritorio, debajo de todo y en todos los escritorios; los fondos se pausan con una ventana a
pantalla completa o maximizada (estado EWMH del gestor de ventanas); las mascotas son ventanas con canal alfa, por encima
de todo y que dejan pasar el raton (con un compositor para ver la transparencia).
